VoyageUA — новий готовий сайт для туристичної агенції.

Що зробити перед здачею:
1. Замініть [Ваше ПІБ] і [Ваша група] у файлах.
2. Відкрийте index.html у браузері.
3. Завантажте всі файли на GitHub.
4. Увімкніть GitHub Pages.

Структура:
- index.html
- tours.html
- about.html
- contacts.html
- css/style.css
- js/script.js
- images/*.svg
